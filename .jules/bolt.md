## 2024-05-25 - [Pre-compile regex for LinkedIn skill categorization]
**Learning:** Python's `re.search` compiled inline inside a tight loop with an f-string (e.g., `re.search(rf"\b{kw}\b", ...)` inside `any()`) forces a regex engine compilation on every single iteration because the string changes dynamically. When matching static lists of keywords, compiling an alternated regex (using `|`) at the module level completely eliminates this overhead.
**Action:** When categorizing strings against large static keyword lists where overlapping matches are not required, always extract the keyword lists into module-level pre-compiled alternated regex patterns (e.g., `re.compile(r'\b(?:kw1|kw2)\b')`) instead of iterating over arrays and compiling regexes inline.
